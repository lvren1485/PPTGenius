# 更新计划与行动方案 — Milestone 2

## Milestone 2 调整后 WBS

### 重点1：RAG 增强模块联调（约 50h）
- 完成大纲生成与RAG检索的端到端集成
- 确保检索内容正确注入每页 PPT
- 优化内容融合策略（素材权重排序、去重、格式统一）

### 重点2：前端界面完善（约 30h）
- 完成 Vue3 前端界面的上传→生成→下载完整流程
- 加入引导提示和默认配置，降低使用门槛

### 重点3：多领域测试与质量评估（约 30h）
- 在商业、教育、科研三个领域各选 2-3 个主题全流程测试
- 对照 Success Criteria 量化评估（结构评分≥4.5/5，可溯源比例≥80%，事实性错误率<5%）

### 重点4：用户测试与迭代（约 50h）
- 设计用户测试方案与问卷
- 邀请 5-8 名目标用户试用
- 建立反馈-修复-验证的迭代机制

### 重点5：文档与最终报告（约 40h）
- 技术报告撰写
- API 与使用文档
- 演示材料准备
