目标：开发为一个软件包

软件概况：
输入：各种配置、路径 以及 用户的messages，将用户的输入文件存放到 —— input path
输出：大纲，然后生成PPT，并保存在指定路径 —— output path
依赖状态：
- workspace：需要一个工作空间来存放软件运行中的数据

工作内容分解：
1. RAG实现 —— 通过BM25算法实现，因为用户输入的文件不会太多；同时添加网络爬取功能，以获取更多相关信息。将所有的文件保存下来，并建立一个知识库，以便在后续的步骤中能够快速查询和使用这些信息。
2. 大纲生成 —— 通过一个generator - evaluator的agent来实现，generator负责生成大纲，evaluator负责评估大纲的质量，并通过循环不断优化大纲，直到达到max_iterations或者评估结果达到预设的阈值。此步需要添加知识库的功能，以便在生成大纲时能够参考相关的知识。在生成完大纲后交获取用户的反馈，并根据用户的反馈进行调整和优化。
大纲生成有三个循环，一是generator与knowledge库的循环，二是generator与evaluator的循环，三是整个体系与用户的循环。
3. PPT生成 —— 生成完整的美观的PPT。包含元素：文本、图形、图片、图表、表格。使用agent - subagent的方式来实现，主agent负责协调各个子agent来完成PPT的生成。子agent包括文本生成agent、图形生成agent、图片爬取agent、数据分析agent、图表生成agent等。每个子agent负责生成对应的元素，并将生成的元素保存下来，以便在后续的步骤中能够快速查询和使用这些元素资源。
    - 文本和图形： 需要规划出多种固定的布局，然后根据布局填充给内容
    - 图片： 需要添加网络爬取功能，以获取相关的图片资源，并将这些图片保存下来，以便在后续的步骤中能够快速查询和使用这些图片资源。问题：模型无多模态能力，无法识别图片内容。或许可以尝试svg格式的图片，或者在爬取图片时同时爬取图片的描述信息，以便在生成PPT时能够根据描述信息来选择合适的图片资源。
    - 数据图表： 添加数据图表功能，python-pptx自身提供一个表格，但是图表比如曲线图等需要使用seaborn或者matplot自行绘制并保存为图片。而且还需要数据分析功能。

总结工作内容：
1. BM25算法实现
2. 网络搜索实现
3. 针对多种格式的文件读取实现：docx，pdf，txt等
4. 将上面的所有内容包装为一个知识库工具，具备存储和查询功能  -> 知识溯源benchmark
5. generator-evaluator的agent实现
6. evaluator评判标准 -> 大纲质量benchmark
7. 大纲生成的用户反馈机制实现
8. workspace管理类实现 -> messages db， file management， rag db， 大纲存储， ppt存储
9. message管理办法，尽量增大缓存命中率，并且进行token计数 -> 成本估计benchmark
10. PPT 模板生成： 指定n个固定的布局模板，包含文本、图形、图片、图表等元素的布局
11. svg与图片爬取功能实现
12. 数据分析功能实现，pandas + seaborn + matplotlib
13. 数据图表生成功能实现，使用seaborn或者matplotlib绘制图表，并保存为图片。要针对图表做类特化，特化为n个类的图表生成工具，以便在生成PPT时能够根据需要来选择合适的图表类型，并且能够根据输入的数据来自动生成相应的图表。
14. PPT生成工具实现，能够根据大纲和用户的需求来生成完整的美观的PPT。协调上面的几个工具，需要输入统一的风格和配色要求，以便在生成PPT时能够保持整体的风格一致性和美观性。
