# PPT-Genius 项目双周报

**汇报周期**：2026-04-27 至 2026-05-17  
**提交日期**：2026-05-17  
**项目名称**：PPT-Genius（基于 LLM 与 RAG 的 PPT 大纲智能生成与内容深度补全系统）

## 一、组内分工

| 成员 | 角色 | 主要分工 |
| --- | --- | --- |
| 潘越 | 组长 | 项目统筹、系统集成与接口设计、集成测试与进度协调 |
| 罗力 | 成员 | LLM 提示词优化、大纲生成逻辑与结构化输出实现 |
| 左凌旭 | 成员 | RAG 检索流程实现、知识库构建与检索模块开发 |

## 二、成员个人双周进展

### 1. 潘越

- 组织模块集成会议，将大纲生成与检索流程在测试脚本中串联，推进接口对齐。
- 设计并整理测试用例集，开始记录结构质量与检索相关性问题。
- 运行初步集成测试，形成“事实性错误率”和“结构评分”的评估方法草案。
- 牵头端到端测试的启动准备，收集测试问题并拆分修复优先级。
- **本阶段工时：18 小时**。

### 2. 罗力

- 基于集成反馈优化 Prompt，提升大纲层级稳定性与页间逻辑连贯性。
- 为每页内容生成检索查询语句，支持 RAG 触发与召回对接。
- 完成“内容融合”初版逻辑，实现生成内容与检索片段的拼接、格式化与去重。
- 开始优化内容粒度控制，并加入“风格参数”的基础设定。
- **本阶段工时：16 小时**。

### 3. 左凌旭

- 优化检索策略，引入关键词 + 向量混合检索，提升召回相关性。
- 为检索结果补充来源溯源信息，输出可用于内容融合与展示的结构化数据。
- 整合溯源信息至返回结构，探索初步事实性校验规则。
- 根据测试中暴露的问题，扩充知识库覆盖范围并调整过滤规则。
- **本阶段工时：18 小时**。

### 4. 上官思洋

- 完善导出模块，支持完整 `EnhancedPPT` 对象导出，并补充基础版式设置。
- 实现引用来源的备注展示，完成导出与可读性体验的联动优化。
- 开发并打通简单 CLI 调用方式，支持快速演示流程。
- 开始整理简要使用说明，并评估轻量展示界面原型。
- **本阶段工时：18 小时**。

## 三、组长汇总

本双周推进了“模块初步集成 + 内容增强 + 导出展示”的主线工作。大纲生成与 RAG 检索完成首次串联，内容融合逻辑初步落地，检索溯源结构具备对接展示与评估的基础；导出模块与 CLI 具备可演示的最小功能形态，端到端测试已启动并沉淀问题清单。

整体进度符合既定规划，下一阶段重点是扩大测试覆盖、稳定结构质量与内容可信度，并继续完善导出效果与用户交互流程。
