# 原始计划回顾 — Milestone 1

## WBS（工作分解结构）

### 一级：项目规划与需求澄清（计划 30h，占 10%）
- 项目立项与范围定义
- 需求调研与场景分析
- 成功标准与度量指标细化

### 二级：叙事结构智能生成模块（计划 80h，占 25%）
- 2.1 结构模板与规则设计
- 2.2 Prompt 设计与调优
- 2.3 大纲质量评估与自动改写

### 三级：RAG 检索与内容补全模块（计划 80h，占 25%）
- 3.1 知识库构建
- 3.2 检索与召回策略设计
- 3.3 内容生成与溯源标注

### 四级：系统原型与交互设计（计划 70h，占 22%）
- 4.1 系统架构与技术选型
- 4.2 前端交互与页面设计
- 4.3 后端服务与流程编排

### 五级：测试、评估与迭代（计划 60h，占 18%）
- 5.1 功能与稳定性测试
- 5.2 用户体验与效果评估
- 5.3 文档整理与成果输出

## RBS（责任分解结构）

### 类别1：叙事结构智能生成
- 需求分析与场景梳理
- 大纲结构模板与叙事范式设计
- LLM 提示词工程（Prompt Engineering）
- 大纲质量评估与优化机制

### 类别2：知识检索与内容深度补全
- 外部知识源与数据域定义
- RAG 检索增强架构设计
- 内容生成与证据对齐
- 事实性与可信度控制

### 类别3：系统与交互支持
- 端到端原型系统架构设计
- 用户工作流设计
- 用户界面与交互体验
- 多角色协作与反馈收集
