# 核心成果详解 — Milestone 1

## 1. LLM 大纲生成模块（完成度 90%）

- **Prompt 工程**：针对商业汇报、学术研究、教育培训三类场景分别设计系统 Prompt，约束标题层级、页间逻辑、内容粒度和叙述风格
- **输入方式**：支持纯主题输入（用户输入一句话主题）和文档输入（上传 PDF/DOCX/TXT，LLM 自动提取核心主题后生成大纲）
- **输出格式**：严格 JSON 结构化输出（`response_format={"type": "json_object"}`），确保后续模块可编程处理
- **生成参数**：temperature=0.6，平衡创意性与结构稳定性
- **真实测试**：使用 DeepSeek API (deepseek-v4-flash) 成功生成"同济大学软件工程课程介绍"5页 PPT

## 2. RAG 检索与内容补全模块（完成度 85%）

- **知识库构建**：完成文档预处理流程（文本分割与清洗），支持从 corpus.json 加载语料
- **向量数据库**：已完成向量数据库的本地部署与接入，支持文档嵌入向量化与存储
- **检索算法**：BM25 检索器（中文正则分词），支持上传文档优先级加权
- **检索策略**：每页检索 top_k=10 个相关知识片段，优先融合用户上传文档内容
- **溯源机制**：每页备注中标注引用素材来源，支持事实核查

## 3. 系统原型与导出模块（完成度 90%）

- **数据模型**：定义了完整的 `Outline` 和 `SlideSpec` 数据结构，包含标题、要点、正文段落、讲者备注、RAG 来源等字段
- **PPT 导出**：基于 python-pptx 库实现完整 .pptx 文件导出，包含标题页、内容页、要点列表和备注
- **模板支持**：创建了简单 PPT 模板（标题页、内容页），可在此基础上扩展

## 4. 集成测试环境（完成度 80%）

- **API 接口**：`PPTGenerator` 类封装完整生成流程，`POST /api/generate` 接口支持 topic + num_slides + 上传文件
- **测试脚本**：编写了端到端流程测试脚本，确保关键功能正确性
- **热加载**：Uvicorn --reload 模式支持开发阶段代码自动重载

## 5. 技术栈

| 层级 | 技术选型 |
|:-----|:---------|
| 后端框架 | Python 3.12, FastAPI, Uvicorn |
| LLM 服务 | DeepSeek API (deepseek-v4-flash), OpenAI SDK |
| 检索 | rank-bm25 (BM25 算法), 中文正则分词 |
| 文档处理 | python-pptx, pypdf, python-docx |
| 前端 | Vue 3, Vite |
| 部署 | 支持 pip install -e . 可安装包 |
