# PPTGenius 前端设计

> Vue 3 + Element Plus + TypeScript
> 日期：2026-06-04

---

## 一、技术选型

| 层面 | 选择 |
|------|------|
| 框架 | Vue 3 (Composition API + `<script setup>`) |
| UI 库 | Element Plus |
| HTTP | axios + 请求拦截器（自动注入 Bearer token） |
| SSE | EventSource / fetch + ReadableStream |
| 路由 | Vue Router 4 |
| 状态 | Pinia（token + user 信息） |
| 构建 | Vite |

---

## 二、路由结构

```
/login                         登录页
/register                      注册页
/                              首页（会话列表）
/conversation/:id              会话详情（消息 + SSE 实时反馈）
/conversation/:id/outline/:oid 大纲详情（slides 预览）
/conversation/:id/ppt/:pid     PPT 详情（slides 状态 + 下载）
/cost                          费用统计
/knowledge                     知识库文件管理
```

**布局**: 上下分区 — 消息区（flex-grow） + 输入区（固定底部） + SSE 状态栏（条件显示）

**消息渲染规则**（按 `role` + `content_type`）:

| role | content_type | 渲染方式 |
|------|-------------|---------|
| user | text | 右对齐气泡，纯文本 |
| assistant | text | 左对齐气泡，Markdown 渲染 |
| file | file | 卡片，显示文件名 + 类型 + 预览摘要 |
| image | image | 卡片，显示文件名 + 路径 + 大小 |

**SSE 事件处理**:

| 事件 | 处理 |
|------|------|
| `phase` | 顶部状态条显示当前阶段文字 |
| `progress` | 顶部状态条显示进度条 `el-progress`（百分比 + 详情文字） |
| `knowledge` | 显示检索到的知识源列表 |
| `outline` | 消息区插入大纲卡片（标题 + 评分 + 页数 + 跳转链接） |
| `ppt_ready` | 消息区插入 PPT 卡片（页数 + 下载链接） |
| `done` | 隐藏进度条，显示耗时 + 费用汇总 |
| `error` | `el-alert` 错误提示（区分可重试/不可重试） |
| `tokens` | 显示 token 用量摘要 |

**Element 组件**:
- **消息区**: `el-scrollbar` → 消息列表（`v-for`）
- **用户消息**: `el-tag` 右对齐
- **AI 消息**: `el-card` + Markdown 渲染
- **文件消息**: `el-card` (shadow=hover) 带图标
- **大纲卡片**: `el-card` + `el-descriptions`（标题/评分/页数）+ `el-button` 跳转
- **PPT 卡片**: `el-card` + `el-button` (download)
- **进度条**: `el-progress` (百分比) + `el-tag`（阶段标签）
- **输入区**: `el-upload`（文件上传按钮）+ `el-input` (textarea) + `el-button` (发送)
- **状态栏**: `el-alert` / 自定义底部条

**API 调用**:
- 加载消息: `GET /api/conversations/:id`
- 发送消息: `POST /api/chat/send`（SSE 流式）
- 上传文件: `POST /api/knowledge/upload`（multipart/form-data）

## 五、SSE 连接管理

会话详情页进入时建立 SSE 连接（仅用于接收历史流），发送新消息时通过 `POST /api/chat/send` 触发，响应本身即为 SSE 流。前端使用 `fetch` + `ReadableStream` 解析 SSE 事件：

```
EventSource 替代方案（支持 POST + 自定义 headers）:
  fetch('/api/chat/send', { method: 'POST', body, headers })
    → response.body.getReader()
    → 逐行解析 "event: xxx\ndata: {...}\n\n"
    → 按事件类型更新 UI 状态
```

连接状态通过 `el-tag`（连接中/已断开/错误）显示在输入区上方。
